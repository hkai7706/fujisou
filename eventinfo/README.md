# Event information pages

The original event archive contains 67 unique entries across six source listing pages. All are represented locally: 66 generated individual pages plus the existing `open-house/index.html`, which is preserved unchanged. The local archive uses five listing pages, newest first, with working links to each detail page.

`posts.json` stores original titles, publication dates, source URLs and complete event content. `import-report.json` records page and image import results. Downloaded body images are stored under `img/eventinfo/articles/`; listing images already used in the project are retained where available. Images are displayed without cropping, with alternative text and dimensions.

Run `node tools/import-event-posts.mjs` to refresh original event information (network access required). The source HTML cache is under ignored `tmp/event-import/`. Run `node tools/build-event-posts.mjs` to regenerate details and listings. Layout uses the shared header/footer from `eventinfo/index.html`, the site serif font, `stylesheet/eventinfo.css`, and `stylesheet/event-detail.css`. The original open-house page is not regenerated by this tool.

Past notices retain their original information, with a short indication that dates, prices and offers refer to publication time. Old embedded forms are replaced by links to the local contact page. Body links between imported events point to local detail files. No event content or photographs are generated.

Run `node tools/generate-sitemap.mjs`, `node tools/site-check.mjs`, and `npm.cmd run build` before deployment. Backup files are untouched.
