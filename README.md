# Fujisou Ainos — Catalog-Based Landing Page

Premium, responsive one-page redesign for フジ創アイノス, rebuilt from the
official Simply, Pretty, and Healthy product catalogs.

## Preview

Open `index.html` directly, or run a local server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Included

- Responsive desktop / mobile design
- Dedicated layouts for wide tablets, iPad portrait/landscape, standard phones,
  small phones, and landscape phones
- iPhone safe-area support, touch-friendly controls, and stacked mobile comparison cards
- Minimal logo-only header (navigation intentionally omitted)
- Semantic Japanese SEO copy
- Open Graph and Twitter metadata
- LocalBusiness / GeneralContractor structured data
- robots.txt and sitemap.xml
- Catalog photography for Simply, Pretty, and Healthy
- Real product positioning, feature comparison, and Healthy's seven-material policy
- Conditional wording for the catalog's long-term warranty program
- Accessible headings, alt text, focus behavior, and reduced-motion support

Before production deployment, confirm the current service area, warranty conditions,
opening hours, and all product specifications. Update the sitemap whenever new pages
are added.
